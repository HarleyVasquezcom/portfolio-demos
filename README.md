# Web Demos — Harley Vasquez

Colección de proyectos frontend/backend autónomos y desplegados individualmente en Vercel.

## Estructura

Cada carpeta dentro de `demos/` es un proyecto independiente y desplegable (estático o con build propio), con su propio `README.md`. El despliegue se hace por carpeta con Vercel CLI:

```bash
vercel --prod
```
