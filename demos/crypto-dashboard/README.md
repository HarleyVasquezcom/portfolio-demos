# Crypto·Term — Dashboard

Simulated market terminal with live-ish ticking candles, sparklines, search, and favorites.

## Features

- 12 crypto symbols with per-asset accent color and seeded 24-tick sparklines
- Auto-ticker every 3s + manual refresh
- Full-text search by symbol/name
- Star-to-favorite filter mode
- Pure DOM rendering (no frameworks), single-file static

## Run

```bash
vercel --prod
```
