# Type Racer — WPM Speed Test

Metallic typing-speed test with live WPM/accuracy, highlighted ghost text and end-of-run metrics.

## Features

- Randomized phrases, click-to-focus invisible input
- Per-character correct/wrong/current highlighting
- Live WPM + accuracy during the run
- Final panel: WPM, accuracy, chars, time, CPS, raw
- Restart + new phrase controls
- Single-file, no dependencies

## Run

```bash
vercel --prod
```
