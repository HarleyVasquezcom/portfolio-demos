# JSON Launder — Format · Validate · Minify

Living-space JSON clean room: paste any JSON and format, validate or minify it in a keystroke.

## Features

- Format with 2 or 4 spaces of indentation
- Minify to a single line
- Live validation with clear error messages
- One-click copy of the output
- Single-file, no dependencies

## Run

```bash
vercel --prod
```
