# Pomodoro Ember

Metallic focus timer with focus/short/long modes, SVG countdown ring, cycle counter and browser notifications.

## Features

- 25 / 5 / 15 minute modes with distinct accent colors
- Smooth SVG progress ring + tabular time display
- Pause/resume/reset/skip controls
- Notification API (desktop) on complete
- Session cycle counter
- Single-file, no dependencies

## Run

```bash
vercel --prod
```
