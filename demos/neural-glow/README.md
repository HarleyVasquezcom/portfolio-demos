# Neural Glow

Interactive canvas particle network: nodes drift, link when close, and repel from your pointer and clicks.

## Features

- 90 glowing particles with wrap-around edges
- Distance-based connective links with fade
- Pointer repel + click shockwave burst
- Live particle/link counters in HUD
- Single-file, no dependencies, RAF loop

## Run

```bash
vercel --prod
```
